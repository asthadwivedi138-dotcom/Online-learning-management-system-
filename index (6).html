📄 C Programming Notes

1. Structure in C

A structure is a user-defined data type used to group different types of variables under one name.

struct Student {
    int id;
    char name[50];
    float marks;
};
2. Pointers

A pointer stores the memory address of another variable.

int number = 10;
int *ptr = &number;
printf("%d", *ptr);
3. Dynamic Memory Allocation

Dynamic memory allocation reserves memory during program execution. Common functions are malloc(), calloc(), realloc() and free().

int *ptr = malloc(5 * sizeof(int));

if (ptr != NULL) {
    ptr[0] = 100;
    free(ptr);
}
4. File Handling

File handling stores and retrieves information from files using functions such as fopen(), fprintf() and fclose().

FILE *fp = fopen("student.txt", "w");

if (fp != NULL) {
    fprintf(fp, "Welcome to LearnHub");
    fclose(fp);
}
5. Important Points
  • Structures group related data of different types.
  • Pointers store memory addresses.
  • Check whether memory allocation succeeds.
  • Use free() to release dynamically allocated memory.
  • Use fclose() to close files.

6. Functions in C

A function is a block of code that performs a specific task. Functions divide a large program into smaller parts and make it easier to understand, test, and reuse. C provides library functions such as printf() and scanf(). Programmers can also create their own functions.

int add(int a, int b) {
    return a + b;
}

7. Arrays in C

An array stores multiple values of the same data type using a single variable name. Each element is accessed using an index starting from 0. Arrays are useful for storing student marks, numbers, and other collections of data.

int marks[3] = {80, 85, 90};
printf("%d", marks[0]);

8. Loops in C

Loops execute a block of code repeatedly. C supports for, while, and do-while loops. A for loop is useful when the number of repetitions is known. Loops reduce repeated code and make programs more efficient.

for(int i = 1; i <= 5; i++) {
    printf("%d ", i);
}

9. Conditional Statements

Conditional statements allow a program to make decisions. The if statement executes code when a condition is true. The if-else statement provides another action when the condition is false.

int age = 18;
if(age >= 18) {
    printf("Eligible to vote");
} else {
    printf("Not eligible");
}

10. Advantages of C

C is a fast and efficient programming language. It supports structured programming, pointers, arrays, and functions. It is commonly used in operating systems, embedded systems, and other applications where performance is important.

📄 Python Programming Notes

1. Class and Object

A class is a blueprint for creating objects. An object is an instance of a class.

class Course:
    def __init__(self, name):
        self.name = name

    def display(self):
        print(self.name)

course = Course("Python")
course.display()
2. List, Tuple and Dictionary
  • List: Ordered and mutable; uses [].
  • Tuple: Ordered and immutable; uses ().
  • Dictionary: Stores key-value pairs; uses {}.
courses = ["C", "Python", "Java"]
days = ("Monday", "Tuesday")
student = {"name": "Astha", "marks": 85}

print(courses[0])
print(student["name"])
3. File Handling

Python uses open() to open files. Common modes are r, w, a and x.

with open("notes.txt", "w") as file:
    file.write("LearnHub Python Notes")

with open("notes.txt", "r") as file:
    print(file.read())
4. Exception Handling

try-except handles errors without abruptly stopping the program.

try:
    number = int(input("Enter a number: "))
    print(10 / number)
except ValueError:
    print("Please enter a valid number")
except ZeroDivisionError:
    print("Cannot divide by zero")
5. Flask and Django

Flask is a lightweight Python web framework. Django provides built-in features for web development. Both can be used to build an LMS backend.

6. Functions in Python

A function is a reusable block of code that performs a specific task. Functions help divide a program into smaller parts, reduce code repetition, and make programs easier to understand. In Python, functions are defined using the def keyword. A function can accept parameters and return a result using the return statement.

def add(a, b):
    return a + b

result = add(10, 20)
print(result)

In this example, add() accepts two numbers and returns their sum. Functions are useful when the same operation needs to be performed multiple times.

7. Loops in Python

Loops are used to execute statements repeatedly. Python provides for loops and while loops. A for loop is commonly used to iterate over a sequence such as a list or string. A while loop continues executing as long as its condition remains true.

for course in ["C", "Python", "Java"]:
    print(course)

count = 1
while count <= 3:
    print(count)
    count += 1

Loops reduce repetitive code and are useful for processing collections, repeating calculations, and automating tasks.

8. Object-Oriented Programming

Object-Oriented Programming (OOP) is a programming approach based on classes and objects. A class defines the properties and behavior of objects. An object is an instance of a class. Python supports important OOP concepts such as inheritance, encapsulation, polymorphism, and abstraction.

class Student:
    def __init__(self, name):
        self.name = name

    def display(self):
        print(self.name)

student = Student("Astha")
student.display()

Here, Student is a class, and student is an object. The __init__() method initializes the object's data, while display() prints the student's name. OOP helps organize larger programs into reusable components.

9. Modules and Packages

A module is a Python file containing reusable code such as functions, classes, and variables. Modules allow programmers to organize code and use it in different programs. Python provides built-in modules such as math, random, and datetime.

A package is a way to organize related modules in a directory. Modules and packages make large projects easier to maintain and help avoid writing the same code repeatedly.

import math

print(math.sqrt(25))
print(math.pi)

10. Advantages of Python

  • Python has simple and readable syntax, making it suitable for beginners.
  • It supports procedural, functional, and object-oriented programming.
  • It has a large collection of libraries and frameworks.
  • Python is used in web development, automation, data analysis, and artificial intelligence.
  • It supports file handling, database connectivity, and rapid application development.

Python is widely used because it allows developers to build applications with relatively little code. However, performance and memory usage should be considered when choosing it for a particular project.

6. Introduction to Python Programming

Python is a high-level, interpreted, general-purpose programming language. It was created by Guido van Rossum and first released in 1991. Python is popular because its syntax is simple, readable, and easy to understand. It is used in web development, data science, artificial intelligence, machine learning, automation, scientific computing, and software development.

Python programs are generally shorter and easier to read than programs written in many other programming languages. Python supports procedural, object-oriented, and functional programming styles. It also provides a large standard library and many external packages.

7. Features of Python

  • Easy to Learn: Python has simple and readable syntax.
  • Interpreted Language: Python code is executed by the Python interpreter.
  • High-Level Language: Programmers do not need to manage most low-level hardware details.
  • Portable: Python programs can run on different operating systems when the required environment is available.
  • Open Source: Python is freely available to use and distribute under its licence.
  • Object-Oriented: Python supports classes, objects, inheritance, and polymorphism.
  • Large Standard Library: Python includes modules for files, mathematics, dates, networking, and more.
  • Dynamic Typing: Variable types are determined at runtime.
  • Extensible: Python can work with libraries and components written in other languages.

8. Applications of Python

Python is used in many fields of computer science and information technology.

  • Web Development: Frameworks such as Django and Flask are used to build web applications.
  • Data Science: Libraries such as Pandas and NumPy help analyse and process data.
  • Artificial Intelligence: Python is widely used to develop AI-based applications.
  • Machine Learning: Libraries help train models and make predictions from data.
  • Automation: Python can automate repetitive tasks such as renaming files and processing reports.
  • Desktop Applications: Libraries such as Tkinter can be used to create graphical applications.
  • Scientific Computing: Python supports numerical calculations, simulations, and research.
  • Cybersecurity: Python can help with authorised security testing and log analysis.

9. Installing Python and Running a Program

To run Python programs, install Python from the official Python website and ensure that the interpreter is available on your computer. An editor such as Visual Studio Code can be used to write Python code. You can run a program from a terminal using the Python command followed by the filename.

print("Hello, World!")

Save the program in a file named hello.py. Depending on your system, run it using python hello.py or python3 hello.py. The output will be Hello, World!

10. Python Syntax and Indentation

Syntax refers to the rules used to write valid statements in a programming language. Python uses indentation to define blocks of code. Indentation is especially important in conditions, loops, functions, and classes. Incorrect indentation can cause an IndentationError.

if 10 > 5:
    print("10 is greater than 5")
    print("This line is inside the if block")

print("This line is outside the if block")

Python commonly uses four spaces for each indentation level. Consistent indentation improves readability and prevents errors.

11. Comments in Python

Comments explain the purpose of code and are ignored by the Python interpreter. A single-line comment starts with the hash symbol (#). Triple-quoted strings are often used for documentation strings, called docstrings, when placed in the appropriate position.

# This is a single-line comment
name = "Astha"  # This is an inline comment
print(name)
